# 个人课表查询

进入工具箱 → 信息查询 → 课表，可以查询指定学期的个人课表。

<img src="../assets/toolUse/timetable.png" width="140">

**操作步骤：**

1. 进入页面后默认显示当前学期的课表
2. 点击顶部的学期选择器，可以切换学年和学期
3. 左右滑动查看不同周数的课程安排
4. 点击任意课程块查看详细信息
5. 底部可查看部分课程QQ群

<img src="../assets/toolUse/qq.png" width="100">

查询结果以与首页日程表相同的形式呈现，支持查看课程详情、教师信息等。
