# 学校文件

进入工具箱 → 通知 → 学校文件，可以查看待阅的学校文件（文印交换系统中的文件）。

<img src="../assets/toolUse/sch files.png" width="120">

**前置要求：**

首次使用时需要登录文件系统的账号密码（与教务系统账号可能不同）。

**登录流程：**

1. 进入页面后，如果未登录，页面显示「未登录」
2. 点击右上角「登录」按钮，弹出登录弹窗
3. 输入文件系统的账号和密码
4. 点击登录按钮
5. 登录成功后自动加载待阅文件列表

**文件列表：**

- 页面顶部显示「待阅文件」标题
- 文件以卡片形式分页显示，每页 10 条
- 底部有页码指示器，显示总页数和当前页码
- 可以左右滑动切换页面

**查看文件：**

点击任意文件卡片，进入文件详情页面查看文件内容。

**空状态：**

- 未登录时显示「未登录」
- 已登录但无待阅文件时显示「暂无待阅文件」
- 加载中时显示加载动画和「内容加载中...」提示

::: tip 提示
文件系统的账号密码可能与教务系统不同，如无法登录请联系学校相关部门确认。
:::
