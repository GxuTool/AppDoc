# 调课信息

进入工具箱 → 通知 → 调课信息，可以查看教务系统发布的课程调动通知。

<img src="../assets/toolUse/course resch.png" width="120">

**页面布局：**

页面顶部有消息类型切换按钮组，包含两个选项：

| 按钮 | 说明 |
|------|------|
| 未读消息 | 显示尚未阅读的调课通知（默认选中） |
| 已读消息 | 显示已经阅读过的调课通知 |

切换按钮后会自动刷新对应类型的列表。

**过滤功能：**

消息类型下方有「仅显示本学期」开关：
- 开启后只显示当前学期的调课通知
- 关闭后显示所有学期的调课通知

**通知列表：**

每条通知以可折叠的列表项显示：

- **标题**：显示「调课提醒：课程名称」
- **时间**：通知的发布时间（灰色小字）

点击通知条目可以展开/收起详细内容。

**调课详情内容：**

展开后显示详细的调课信息，自动解析通知文本并结构化展示变动内容：

| 字段 | 说明 |
|------|------|
| 教师 | 教师变动（如有） |
| 周次 | 上课周次变动（如有） |
| 星期 | 上课星期变动（如有） |
| 节次 | 上课节次变动（如有） |
| 地点 | 上课地点变动（如有） |

**变动标识规则：**

- 未变动的字段不显示
- 原值以 ~~删除线~~ 标记，颜色为灰色
- 新值以 **绿色粗体** 标记
- 箭头图标（→）连接原值和新值

展开区域底部还会显示通知的原始全文，方便查看完整的调课说明。

::: warning 注意
发生调动的课程请及时关注，以免走错教室或错过课程。建议在上课前再次确认课程安排是否正确。
:::
